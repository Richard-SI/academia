## Deploy no Netlify (recomendado)

### Opção 1 — Conectar via GitHub (deploy automático)

1. Faça o push deste repositório para o GitHub
2. Acesse [netlify.com](https://netlify.com) e crie uma conta gratuita
3. Clique em **Add new site → Import an existing project**
4. Conecte sua conta do GitHub e selecione este repositório
5. Deixe as configurações padrão e clique em **Deploy site**
6. Pronto! A cada `git push`, o site atualiza automaticamente

### Opção 2 — Upload manual

1. Acesse [netlify.com](https://netlify.com)
2. Arraste a pasta do projeto para a área de deploy
3. Site no ar em segundos

## Domínio personalizado

Para usar um domínio próprio (ex: `richardpersonal.com.br`):

1. Compre o domínio no [Registro.br](https://registro.br) (~R$40/ano)
2. No Netlify: **Domain settings → Add custom domain**
3. Aponte o DNS conforme as instruções do Netlify
4. HTTPS é ativado automaticamente
